A Python program — standard library only, no network — that writes one line to /output/entry.txt: a funny fortune cookie message for an AI agent, in the voice of a fortune slip. The line is 80 characters, inside the competition's gate of 1 to 140 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
